# 플래너 코치 AI (2인용 학습 플래너 검사기 · 주간 분석 리포트)

종이 스터디 플래너를 **스마트폰에서 앱을 실행해 직접 사진으로 찍으면** **Google Gemini API(본인 API 키)** 로 분석하여,
1. **Before → After 계획 수정안**
2. **나노바나나 기본형(`gemini-nano-banana-2.1`) 색상 교정 예시 그림 + 과목별·학습성격별 모범 타임테이블(PNG)**
3. **날짜별 성경읽기 패턴 분석 & 내일 성경읽기 제안** (`🎓 김희균`은 `bible71` DB 실시간 패턴 분석 · `🌱 초등학생`은 종이 플래너 기록 기반 다음 분량 제안)
4. **플래너 여백에 직접 손으로 베껴쓸 수 있는 핵심 습관·내일 예약 필사 박스**
5. **누적 데이터(로컬 DB + 내 구글 드라이브) 기반 4단계 주간 공부 분석 & 진도 예측 리포트**
6. **카카오톡 원터치 전송 · A4 PDF 저장 · 프린터 직접 인쇄**

까지 한 번에 처리하는 **김희균(고등학생) 전용 + 초등학생 맞춤형 학습·경건 코칭 앱**입니다.

---

## 📖 날짜별 성경읽기 패턴 분석 & 내일 제안 구조

* **🎓 김희균 (고등학생 · `/Users/kbd/Desktop/bible71` DB 실시간 패턴 분석)**:
  * 고정 맥체인 날짜표를 일률적으로 강요하는 대신, `bible71`의 Supabase `reading_logs`(`completed_at` 타임스탬프·날짜·본문·장수)를 읽어 **실제 읽는 요일 분포, 평균 간격(일), 주로 읽는 KST 시간대, 최근 본문 및 회당 평균 장수**를 자동 분석합니다.
  * 마지막으로 읽은 책과 장수·속도에 맞춰 **내일 성경읽기 추천 본문**(예: 빠진 요일 보완 + 다음 장 이어 읽기)을 일일·주간 리포트에 함께 제시합니다.
* **🌱 초등학생 (종이 플래너 기록 기반 이어 읽기 제안)**:
  * 초등학생은 `bible71` 앱을 사용하지 않으므로 **종이 플래너에 읽은 성경 분량을 직접 손으로 적게 한 뒤**, 사진을 찍으면 AI가 기록 여부를 판독하고 누적 기록을 바탕으로 내일 읽을 다음 장(`예: 잠언 2장`)을 자연스럽게 제안합니다.
* **🍌 나노바나나 기본형(`gemini-nano-banana-2.1`) 모범 플래너 이미지**:
  * 폰으로 찍은 종이 플래너 원본 사진 + Before→After 수정안 + 과목별 색상 규칙을 `gemini-nano-banana-2.1`에 전달해 색칠 교정 예시 이미지를 생성하고, 코드로 그린 선명한 10분/30분 타임테이블 및 베껴쓰기 박스와 함께 보여줍니다.
* **🎯 관리자 개입형 습관 형성 도구**:
  * **이번 주 집중 코칭 습관(1~4단계)** 선택기 및 **어제 손글씨 약속 이행 여부(+10점 보너스)** 확인 기능을 통해 종이 플래너 작성 습관을 단계적으로 잡아줍니다.

## 🚀 방법 1: 빌드 없이 지금 바로 실행하기 (`web-app/`)

Mac이나 스마트폰에서 별도의 안드로이드 스튜디오 빌드 없이 바로 실행해 볼 수 있습니다.

```bash
cd /Users/kbd/Desktop/planner/web-app
python3 -m http.server 8080
```

- 브라우저에서 `http://localhost:8080` 접속
- 안드로이드 폰(같은 Wi-Fi)에서 접속 후 크롬 메뉴 → **홈 화면에 추가**를 누르면 네이티브 앱처럼 설치되어 **카메라 촬영, 카카오톡 공유, PDF 저장, 무선 인쇄**를 바로 사용할 수 있습니다.
- 첫 화면의 **`체험용 7일 샘플 채우기`** 버튼을 누르면 고등학생/초등학생 주간 리포트, PDF 저장, 인쇄 결과를 즉시 미리볼 수 있습니다.

## 📱 방법 2: 안드로이드 네이티브 APK 빌드하기 (`android-app/`)

1. **Android Studio**에서 `/Users/kbd/Desktop/planner/android-app` 폴더를 열기(`Open`) 합니다.
2. Gradle 동기화가 완료되면 안드로이드 폰을 USB/Wi-Fi 디버깅으로 연결하고 **Run (`▶`)** 또는 **Build > Build Bundle(s) / APK(s) > Build APK(s)**를 실행합니다.
3. 앱 실행 후 하단 **설정 탭**에서:
   - 보유하신 **Google Gemini API 키** 입력 (기본 모델: `gemini-4-hydrogen`)
   - 🎓 고등학생 / 🌱 초등학생 이름 설정
   - **구글 드라이브 폴더 연결** 또는 **Apps Script 웹훅 URL** 연결

## ☁️ 내 구글 드라이브 자동 누적 연동 방법

1. [Google Apps Script](https://script.google.com) 접속 → **새 프로젝트** 생성
2. `web-app/google-drive-script.gs` 파일 내용을 그대로 복사해 붙여넣기
3. 우측 상단 **배포 > 새 배포 > 유형: 웹 앱** 선택 (실행 주체: *나*, 액세스 권한: *모든 사용자*)
4. 발급된 **웹 앱 URL**을 앱의 `[설정 → Apps Script 웹훅 URL]`에 입력
5. 이후 검사할 때마다 내 구글 드라이브 안에 아래 파일들이 자동으로 누적됩니다:
   - 📁 `플래너검사기_데이터/고등학생_누적기록/` (일일/주간 리포트 PNG & PDF)
   - 📁 `플래너검사기_데이터/초등학생_누적기록/` (일일/주간 리포트 PNG & PDF)
   - 📊 `누적_플래너_학습기록` (구글 스프레드시트 자동 기록)
   - 📄 `planner_backup_db.json` (기기 변경 시 전체 데이터 원클릭 복원용)

## ☁️ 클라우드 버전 (Supabase · 2026-11)

모든 기록은 Supabase(`mathtox` 조직 / `planner` 프로젝트, 서울)에 저장되어 휴대폰·Mac 등 모든 기기에서 동기화됩니다.

| 화면 | 주소 | 로그인 |
|---|---|---|
| 관리자 앱 | `https://kbd71.github.io/planner/` (index.html) | 관리자 이메일 |
| 학생용 앱 | `https://kbd71.github.io/planner/student.html` | 아이디(예: hg5) + 비밀번호 |

**흐름**: 학생이 플래너 촬영·제출 → 관리자 앱 📥 받은 플래너에서 열기 → AI 분석(엔진 선택) → 확인·수정 → 📤 학생에게 보내기 → 원본 사진 자동 삭제, 교재·진도·습관 자동 누적 → 학생 앱에서 리포트·진도 확인.

- **분석 엔진**: 설정에서 Gemini / mlx-serve(Mac 로컬) / mlx-serve 먼저 후 Gemini 중 선택
- **리포트 형태**: 그림 포함(AI 첨삭 그림) / 보고서만. 첨삭 그림은 보낸 뒤 7일이 지나면 저장공간에서 자동 삭제(리포트 데이터는 유지)
- **진도 관리**: 플래너의 교재·쪽수를 AI가 숫자로 읽어 `materials`, `study_tasks`에 자동 기록. 주간리포트 탭에서 교재별 전체 분량·목표일을 넣으면 진도율·예상 완료일 계산
- **DB 설계**: `supabase/001_schema.sql`, `supabase/002_study_tracking.sql`
- **학생 계정 추가**: Supabase 대시보드 → Authentication → Add user (`아이디@planner.local`, Auto confirm) 후 SQL로 `profiles.student_type`, `display_name` 지정
